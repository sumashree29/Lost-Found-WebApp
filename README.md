# Lost & Found Web App

Find, post, and claim lost items on campus. Fast, simple, and mobile‑friendly.

## Highlights
- 🔍 Search and smart filters
- 📸 Image uploads
- 🔐 Google sign‑in
- ⚡ Real‑time updates (Firebase)
- 📱 Responsive UI (React + Tailwind)

## Quick Start
```bash
npm install
npm run dev
# open http://localhost:5173
```

## Deploy (GitHub Pages)
This repo includes a workflow that builds and deploys on every push to `main`.
- Settings → Pages → Source: GitHub Actions
- Done. It publishes automatically.

## Configure Firebase (optional)
Edit `src/firebase.js` with your Firebase project config to enable auth, Firestore and Storage.

## Tech
React + Vite + Tailwind CSS + Firebase
